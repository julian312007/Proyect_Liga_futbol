Liga de Fútbol: ingresar con Google

Inicia sesión con tu cuenta de Google. La API verifica tu identidad y te entrega un token propio para usar en Swagger.

Token propio (válido por minutos):

  1. Abre Swagger UI.
  2. Pulsa Authorize, pega el token (sin escribir "Bearer") y confirma.
  3. Ya puedes probar los endpoints con tu rol.
